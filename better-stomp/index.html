Architecture

Three places, each doing only what it must: the player's PC, one small server on Cloudflare, and the external APIs behind it.

Local only where it must be

The app talks to the League client through a short allow-list of endpoints and reads live game data from a read-only local port. No memory reading, no injected code, nothing the game does not already show.

A narrow bridge

The interface runs in a sandboxed renderer. It reaches the system only through a small preload API, so the UI never holds a credential or opens a socket of its own.

One small server

A Cloudflare Worker proxies the Riot Games API, so the key never ships inside the app. Requests are rate-limited per route, and patch summaries are cached in KV.

Statistics on a budget

A cron trigger fires every minute, pulls a few ranked games and folds them into D1. Each run fits in about 10 ms of CPU, so the whole pipeline lives on the free tier.

The heart of the pipeline

Every minute the Worker reads a few finished ranked games. This function folds one of them into the running totals: games and wins per champion and role, and the lane opponent for matchup statistics. Remakes and short games are thrown away first.
