Under the hood

The screens above show what each product does. Here is how it works: a piece of real source from every project, and the decision behind it.

Better
Stomp

A Cloudflare cron runs every minute, pulls a handful of ranked Solo/Duo games from the Riot API and folds them into per-champion, per-role aggregates in D1. Each run has to fit in 10 ms of CPU, so every row is a small JSON blob rewritten only when touched.

Electron · Cloudflare Workers · D1 · Riot API

Read the case study →

FieldBot

The model never touches the database. It calls four typed tools, and every argument it sends is parsed and validated before the booking engine runs. Domain, application, AI and API live in separate projects, one handler per feature.

.NET 10 · EF Core · PostgreSQL · Claude API · Docker

In development

Smart­Archivista

The licensing server behind the desktop app: activations over HMAC-signed requests, a cap on active installations, per-minute rate limits kept in MySQL, and Stripe subscriptions kept in sync through verified webhooks.

PHP · MySQL · Stripe

smartarchivista.it →

Open DPP

Domain rules live in pure PHP that never touches the database, so they are easy to test: validation, completeness and which fields each role may see. A barcode is checked down to its last digit before it is saved, and the QR code is generated by an encoder written for the plugin.

PHP · WordPress · REST API · WooCommerce

TCG Profit
Lab

A zero-dependency Python server bound to 127.0.0.1 proxies the eBay and Yahoo! Shopping APIs and daily exchange rates. The browser does the maths: landed cost, ROI, break-even price and a 10,000-run simulation of opening a box.

Python · JavaScript · Frankfurter FX
